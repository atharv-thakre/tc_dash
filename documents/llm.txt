# tc_auth — AI Documentation Manifest

> `tc_auth` is a modular, production-ready authentication and authorization library for FastAPI applications with SQLAlchemy. It features decoupled initialization (`connect.py` / `run.py`), dual-token JWT architecture (access + rotating refresh tokens), server-side session hashing, password policy enforcement, Google/GitHub/Discord OAuth 2.0 with safe linking, SMTP OTP & Magic Links, and role/status-based dependency injection guards.

## Hosted Documentation Root
Base URL: `https://auth.codesena.me/documents`

## Core Architectural Rules for AI Agents
- Always instantiate database and Auth in `connect.py` (`auth = Auth(engine=engine)`).
- Never pass `app` into `Auth` in modular apps to avoid circular imports.
- In feature routers, import `auth` from `connect` and use `auth.deps.get_current_user`, `auth.role.require("role")`, `auth.status.require("active")`.
- Mount routes in `run.py` via `auth.include_routes(app, prefix="/tc-auth")`.
- Pass access tokens in `Authorization: Bearer <access_token>` headers.
- Pass refresh tokens only in `POST /tc-auth/token/refresh`.
